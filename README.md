🎬 Movix – Movie Search Website

Movix is a responsive movie search website that allows users to search for movies and explore their details using the OMDb API.

The project is built using HTML, CSS and JavaScript, with a simple and user-friendly interface.

✨ Features

- 🔍 Search movies by title.
- 🎞️ View movie suggestions with posters.
- 📅 Display movie release years.
- ⭐ Explore movie ratings and release dates.
- 🎭 View genres, actors and writers.
- 📝 Read movie descriptions and plots.
- 🏆 Display movie awards and language information.
- 📱 Responsive design for different screen sizes.

🛠️ Technologies Used

- HTML5 – Website structure.
- CSS3 – Styling and responsive layout.
- JavaScript – Search functionality and API integration.
- OMDb API – Movie information and search results.
- Font Awesome – Icons.

🚀 Getting Started

Follow these steps to run the project locally.

1. Clone the repository

git clone YOUR_GITHUB_REPOSITORY_URL

2. Open the project folder

cd movie-search-app

3. Run the website

Open "index.html" in your browser.

No additional installation is required.

🔑 API Configuration

This project uses the "OMDb API" (https://www.omdbapi.com/) to retrieve movie information.

To configure your own API key:

1. Obtain an API key from OMDb.
2. Open "script.js".
3. Replace the existing API key with your own key.
4. Use HTTPS for API requests.
